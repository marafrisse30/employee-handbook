# Employee Handbook — scrolling presentation

Вертикальная веб-презентация Buyut Aljiwar со встроенной структурой компании.
Все библиотеки, фотографии и исходный PDF включены. Сборка и установка программ не нужны.

## Просмотр
Откройте index.html в браузере и прокручивайте вниз.

## GitHub Pages
Распакуйте архив. Загрузите его содержимое в корень репозитория через Add file → Upload files, заменив совпадающие файлы. Не загружайте сам ZIP или внешнюю папку.
В Settings → Pages оставьте main / (root). Дождитесь публикации и обновите страницу.
Папку assets загружайте целиком. Старые hub.js, hub.css, app.js, style.css в корне новой страницей не используются.

## Файлы
index.html — главная страница.
presentation.js — содержимое и GSAP-анимации.
presentation.css — оформление.
content.js — команда, отпуска и дресс-код.
chart.js и chart.css — интерактивная структура компании.
assets/employee-handbook.pdf — оригинальный документ.

Содержание основано на предоставленном PDF. Полный текст доступен по кнопке PDF. Должности команды приведены по handbook; схема с Managing Director и CSO сохранена отдельно по согласованной структуре.

GSAP 3.15.0 и ScrollTrigger находятся в assets/vendor. Учтена системная настройка Reduce Motion.
https://gsap.com/standard-license/

Статическая версия не содержит авторизации. При публикации на общедоступном сайте PDF и фотографии также доступны посетителям.
